## Overview

Start building disruptive products easily with AAMP Development.

## Steps

<Steps>
  <Step title="Create project on dashboard">
    ````
    Go to your AAMP dashboard and click "New Project".
    Fill out the project name and select a template.
    Click "Create".
    ````
  </Step>
  <Step title="Clone your project">
    ````bash
    git clone https://git.aampdev.com/yourproject.git
    cd yourproject
    ````
  </Step>
  <Step title="Start development">
    ````bash
    npm install
    npm start
    ````
  </Step>
</Steps>
